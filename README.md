# Second Pass

A STEM refresher (maths, algebra, physics, chemistry, astronomy, biology) packaged as an installable, offline web app.

## Publish with GitHub Pages

1. Upload everything in this folder to the root of the repository, keeping the folder structure (`index.html` must sit at the top level, alongside `sw.js`, `manifest.webmanifest`, `docs/`, `pages/`, `video/` and `icons/`).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose **main** and **/ (root)**, then **Save**.
4. After a minute or two the app is live at `https://mickc82.github.io/Learning-Package/`.

The repository must be public for GitHub Pages on a free account.

## Install

- **iPad or iPhone:** open the address in Safari, tap **Share → Add to Home Screen**.
- **Windows:** open the address in Edge or Chrome and choose **Install** (the button on the home page, or the install icon in the address bar).

Open the app once while online and wait until the status reads **Ready offline**. Open one workbook while online too, so the maths display library is saved; after that everything works without a connection.

## Updating

Replace the changed files and push. The app picks up the new version the next time it is opened online.

Progress (ticks, workbook answers) is stored on each device and does not sync between devices.


*** Note this entire project is AI generated based on prompts by the end user. The material and Web App was generated with Opus 5.5 as a test case. ***
